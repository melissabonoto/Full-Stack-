Jogo

Descrição

Controle um peixe no oceano. Coma peixes menores para crescer e
evite peixes maiores para não ser comido.

Como Jogar

Utilize as teclas "← ↑ → ↓" para se movimentar.

Encoste nos peixes menores para comê-los e aumentar de tamanho.
Se enconstar em peixes maiores, perderá uma vida. Você tem 3 vidas.

Seu objetivo é atingir o tamanho 100. Boa sorte!
